# Sources

The official documents behind the exam specification, including sample papers. The repository is public and sample papers are under copyright, so every file in this directory except this index is encrypted with git-crypt (see [.gitattributes](../../.gitattributes)); `git-crypt unlock` opens them. This index holds only links and our own summary, and stays readable.

## Access note

`ucy.ac.cy` sits behind Cloudflare and blocks non-browser clients (curl, WebFetch: HTTP 403), whatever the User-Agent. Headless Chrome (`google-chrome --headless=new --dump-dom`) passes; the PDFs were fetched with `fetch()` from a page of the site opened in headless Chrome.

`greek-language.gr` serves plain curl. The two KEG pages were printed with `google-chrome --headless=new --print-to-pdf`; the speaking page with its collapsed sections opened by CSS, so that every level's scale is in the PDF.
